Healthcare Survival Analysis
1. Project Overview
This project investigates the association between targeted HER2 therapy and overall survival in patients with HER2-positive breast cancer.
2. Research Question
Is targeted HER2 therapy associated with improved overall survival compared with standard of care alone?
3. Methods
Data cleaning and preprocessing
Kaplan-Meier Survival Analysis
Log-rank Test
Cox Proportional Hazards Regression
